Credit Store

Use o script shell no terminal para preparar e iniciar o backend Next.js. O navegador não pode executar scripts shell por segurança.

git clone https://github.com/callonlogin-ops/credit-store.git
cd credit-store
chmod +x Index.sh Start.sh
./Start.sh install
nano .env.local
./Start.sh migrate
./Start.sh start

Depois abra a página de cadastro e upload.

Google Play Console · Windows ISO oficial

Não execute fastboot flash boot sem confirmar modelo, imagem, bootloader e backup. O Credit Store não precisa de fastboot.
