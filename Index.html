Credit Store

Central de instalação, execução e links oficiais do projeto. Esta página é apenas uma interface web: ela não executa comandos do sistema, não faz flash em aparelhos e não instala imagens ISO.

Abrir repositório Play Console Ver Start.sh

Instalação

Execute os comandos abaixo em um terminal Linux, macOS ou Termux.

git clone https://github.com/callonlogin-ops/credit-store.git cd credit-store chmod +x Index.sh Start.sh ./Start.sh install nano .env.local ./Start.sh start

Segurança

Não execute fastboot flash boot sem confirmar o modelo do dispositivo, a imagem correta, o bootloader e possuir backup. Um flash incorreto pode inutilizar o aparelho e apagar dados. O Credit Store não precisa de fastboot para funcionar.

Não coloque senhas, tokens, chaves de API, credenciais bancárias ou documentos pessoais no HTML, no repositório ou no arquivo .env versionado.
